# WardenArmorPlugin

Плагин для Paper/Spigot, добавляющий комплект «Брони Вардена» с эффектом ауры из блоков скалка и способностью **Sonic Boom** по нажатию клавиши **F**.

## Автор

**mscgroup**

## Возможности

- 🛡️ **Комплект брони Вардена** — незеритовые шлем, нагрудник, штаны и ботинки с кастомными названиями, Защитой IV и Прочностью III.
- 🌌 **Аура Вардена** — вокруг игрока в полном комплекте вращаются 6 светящихся блоков скалка (реализовано через `BlockDisplay`).
- 💥 **Sonic Boom** — при нажатии **F** (свободная левая рука) игрок выпускает звуковую волну:
  - визуальный луч из частиц `SONIC_BOOM` длиной до 15 блоков;
  - урон 10 единиц (5 сердец) всем живым сущностям на пути;
  - отбрасывание цели от игрока;
  - перезарядка **5 секунд**.
- 🧹 Аура автоматически удаляется при выходе игрока с сервера и при выключении плагина.

## Требования

| Компонент | Версия |
|-----------|--------|
| Сервер    | Paper 1.21.11 (или совместимый форк) |
| Java      | 21+ |
| Maven     | 3.8+ (для сборки) |

## Установка

1. Скачайте готовый `.jar` или соберите его самостоятельно (см. ниже).
2. Поместите файл `WardenArmorPlugin-1.0.0.jar` в папку `plugins/` вашего сервера.
3. Перезапустите сервер.

## Сборка

```bash
mvn clean package
```

Готовый файл появится в `target/WardenArmorPlugin-1.0.0.jar`.

## Использование

### Команда

```
/givewardenarmor [игрок]
```

- Без аргументов — выдаёт броню себе.
- С аргументом — выдаёт броню указанному игроку.
- Команда доступна только игроку с ником `Depervs` (см. константу `OWNER_NAME` в коде).

### Способность

1. Наденьте **полный комплект** брони Вардена.
2. Убедитесь, что левая рука пуста.
3. Нажмите **F** — сработает Sonic Boom.

> Если надета не вся броня Вардена, способность и аура не активируются.

## Настройка

Основные параметры находятся в начале класса `WardenArmorPlugin`:

| Константа | Значение | Описание |
|-----------|----------|----------|
| `OWNER_NAME` | `Depervs` | Ник игрока, которому разрешена команда |
| `COOLDOWN_MS` | `5000` | Перезарядка способности (мс) |
| `AURA_BLOCKS` | `6` | Количество блоков в ауре |
| `AURA_RADIUS` | `1.2` | Радиус вращения ауры |
| `AURA_HEIGHT` | `1.0` | Высота центра ауры над игроком |

Параметры Sonic Boom (урон, дальность, шаг) задаются в методе `activateSonicBoom`.
